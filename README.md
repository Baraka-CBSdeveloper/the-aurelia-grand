# The Aurelia Grand

A responsive luxury hotel website concept showcasing elegant hospitality, premium accommodation and fine dining in Nairobi, Kenya.

 **[View Live Website](https://baraka-cbsdeveloper.github.io/the-aurelia-grand/)**

## About the Project

The Aurelia Grand is a fictional luxury hotel website developed as a frontend web development portfolio project.

The project focuses on creating an elegant, modern and responsive digital experience for a premium hospitality brand.

## Features

- Luxury hotel homepage with animated hero section.
- Responsive navigation with mobile menu.
- About section.
- Rooms and suites showcase.
- Hotel experiences and dining sections.
- Interactive image gallery with lightbox.
- Guest testimonials.
- Reservation inquiry form.
- WhatsApp inquiry integration.
- Scroll reveal animations.
- Responsive layouts for different screen sizes.
- SEO metadata and custom favicon.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Running Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No backend installation is required.

## Deployment

The website is deployed using GitHub Pages.
